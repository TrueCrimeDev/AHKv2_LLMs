Tinsel, the elf who wrote every AutoHotkey script in the North Pole control room, left for a beach and took the documentation with her. Five systems now misbehave, and the sleigh launch script refuses to run until you fix all five.

- Five days, two parts each. Part 2 unlocks after Part 1 and uses the same input.
- Each part awards a golden keycap.
- Every answer is an integer that fits in AutoHotkey's native 64-bit Integer.
- Each day has a small example with known answers and a full input file.
- Puzzle rules win wherever they differ from real AutoHotkey behavior. The puzzles borrow AutoHotkey syntax for flavor and never need a real keystroke sent.
- Each day ends with an optional alpha challenge: solve it again with a named v2.1-alpha feature.

| Day | Title | Puzzle type | Part 2 twist |
| :-- | :-- | :-- | :-- |
| 1 | Send Help | Parsing and counting | Reinterpret the same text as physical key wear |
| 2 | Hotstring Hangover | Text expansion | Recursive growth too large to build as a string |
| 3 | Window Pains | Rectangles on a grid | Z-order decides who owns each pixel |
| 4 | Caret Maze | Shortest path | New moves that slide until they hit a wall |
| 5 | Alt-Tab Avalanche | List simulation | Repeat the macro a trillion times |

Any v2 release can solve this tier. When it feels easy, switch to the alpha tier.
